# Towers of Hanoi

##  Description

This project was my **first programming project**, completed during the **first semester of the first year of a Bachelor's degree in Computer Science (L1)**.

The project focuses on implementing the **Towers of Hanoi** puzzle using **Python**, with a graphical visualization using the **Turtle** library.

The goal was to apply the programming concepts learned during the first semester, including functions, lists, loops, conditions, recursion, and user interaction.

##  Objectives

* Implement the basic rules of the Towers of Hanoi.
* Represent the game board using Python lists.
* Check whether a move is valid.
* Detect when the game is completed.
* Display the game graphically using Turtle.
* Implement a recursive algorithm to find the solution.
* Add a simple menu and score management.

##  Features

* Initialization of the game with a chosen number of disks.
* Validation of disk movements.
* Interactive gameplay through user input.
* Graphical representation of the towers and disks.
* Undo the last move.
* Score and game time management.
* Display of rankings.
* Automatic solution using a recursive algorithm.
* Animation of the solution using Turtle.

##  Technologies

* **Python**
* **Turtle**
